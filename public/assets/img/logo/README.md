# Logotip oficial d'INLLOBSA

`inllobsa-logo.png` prové del fitxer del logotip facilitat per INLLOBSA. Només s'ha retallat el marge blanc
i s'ha fet transparent el fons. Les proporcions i els colors són els originals.

Si disposeu del logotip en format vectorial (SVG), substituïu-lo: deseu-lo com a `inllobsa-logo.svg`,
canvieu l'extensió a `src/template.html` (cerqueu `inllobsa-logo`) i executeu `node build.mjs`.
Es veurà més nítid en pantalles d'alta densitat.
