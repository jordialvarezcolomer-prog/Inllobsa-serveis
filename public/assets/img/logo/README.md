# Logotip oficial d'INLLOBSA

Deixeu aquí els fitxers del nou logotip **amb aquests noms exactes**:

| Fitxer | Ús |
| --- | --- |
| `inllobsa-logo.svg` | Capçalera (fons blanc). Versió a color. |
| `inllobsa-logo-negatiu.svg` | Peu de pàgina (fons blau fosc). Versió en blanc/negatiu. |

- Format recomanat: SVG. Si només hi ha PNG, deseu-lo amb el mateix nom però extensió `.png`
  i canvieu l'extensió a `src/template.html` (dues línies, cerqueu `inllobsa-logo`), i després executeu `node build.mjs`.
- L'alçada es fixa a 40 px i l'amplada s'adapta automàticament, de manera que es respecten les proporcions.
- Mentre el fitxer no hi sigui, la web mostra només el nom «INLLOBSA» en text pla.
  No és cap logotip provisional.
- Quan tingueu el logotip, podeu substituir també `../favicon.svg` per una versió reduïda del símbol.
